# Implementation Plan: Gameplay Interaction

**Branch**: `scribble-app` | **Date**: 2026-06-04 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/003-gameplay-interaction/spec.md`

## Summary

Extend the existing Scribble Assignment to support full gameplay: the drawer uses the HTML5 Canvas API to draw freehand strokes (normalized coordinates, one POST per completed stroke); guessers submit text guesses and receive immediate correct/incorrect feedback; all players see a live chronological guess history. The Game screen gains a ~2-second polling interval (replacing the one-time fetch from Scenario 2). All state lives in the existing in-memory room store.

## Technical Context

**Language/Version**: TypeScript 5.x (Node.js 20+ backend, React 18 frontend)

**Primary Dependencies**: Express 5 (backend), React Router v6 (frontend), Vitest 3.1.3 (backend tests), Zod (schema validation), native HTML5 Canvas API (no new drawing library)

**Storage**: In-memory `Map<string, Room>` — no database

**Testing**: Vitest (`backend/src/services/roomStore.test.ts`)

**Target Platform**: Local development web app (Node.js server + Vite dev server)

**Performance Goals**: Strokes and guesses visible to all players within ~2 s of creation (governed by ~2 s Game screen poll interval)

**Constraints**: No new top-level dependencies. No WebSockets. No persistent storage. Native Canvas API only. All changes must extend existing patterns.

**Scale/Scope**: 2–6 players per room, single active game per room, assignment duration only

### Phase 2 — Backend Service Changes

**File**: `backend/src/services/roomStore.ts`

**`createRoom()`**: Initialize `strokes: []` and `guesses: []` in the Room object literal.

**`startRoom()`**: Reset `room.strokes = []` and `room.guesses = []` when the game begins (ensures fresh state for each game).

**`toRoomSnapshot()`**: Include `strokes: room.strokes.map(s => ({ points: [...s.points] }))` and `guesses: room.guesses.map(g => ({ ...g }))` in the returned snapshot.

**New `addStroke(code, participantId, stroke)`**:
```typescript
export function addStroke(code: string, participantId: string, stroke: Stroke) {
  const room = rooms.get(code);
  if (!room) return { error: "room_not_found" as const };
  if (room.status !== "game") return { error: "not_in_game" as const };
  if (room.drawerId !== participantId) return { error: "not_drawer" as const };
  room.strokes.push({ points: [...stroke.points] });
  room.updatedAt = now();
  rooms.set(room.code, room);
  return { room: cloneRoom(room) };
}
```

**New `submitGuess(code, participantId, text)`**:
```typescript
export function submitGuess(code: string, participantId: string, text: string) {
  const room = rooms.get(code);
  if (!room) return { error: "room_not_found" as const };
  if (room.status !== "game") return { error: "not_in_game" as const };
  const trimmed = text.trim();
  if (!trimmed) return { error: "empty_guess" as const };
  if (room.drawerId === participantId) return { error: "drawer_cannot_guess" as const };
  const caller = room.participants.find((p) => p.id === participantId);
  if (!caller) return { error: "participant_not_found" as const };
  const alreadyCorrect = room.guesses.some(
    (g) => g.participantId === participantId && g.isCorrect
  );
  if (alreadyCorrect) return { error: "already_correct" as const };
  const isCorrect =
    trimmed.toLowerCase() === (room.currentWord ?? "").trim().toLowerCase();
  const guess: GuessEntry = {
    participantId,
    name: caller.name,
    text: trimmed,
    isCorrect,
    submittedAt: now()
  };
  room.guesses.push(guess);
  room.updatedAt = now();
  rooms.set(room.code, room);
  return { isCorrect, guess: { ...guess } };
}
```

### Phase 3 — Backend API Changes

**File**: `backend/src/api/schemas.ts` — add:
```typescript
export const addStrokeSchema = z.object({
  participantId: z.string(),
  stroke: z.object({
    points: z.array(
      z.object({ x: z.number().min(0).max(1), y: z.number().min(0).max(1) })
    ).min(1)
  })
});

export const submitGuessSchema = z.object({
  participantId: z.string(),
  text: z.string()
});
```

**File**: `backend/src/api/rooms.ts` — add two new route handlers after the `/:code/start` handler:

`POST /:code/strokes` — validates caller is drawer, appends stroke, returns updated RoomSnapshot.

`POST /:code/guesses` — validates caller is guesser, not already correct, text non-empty; computes `isCorrect`; appends GuessEntry; returns `{ isCorrect, guess }` without `currentWord`.

Error mapping:
- `room_not_found` → 404
- `not_in_game` → 400
- `not_drawer` / `drawer_cannot_guess` / `already_correct` → 403
- `empty_guess` → 400
- `participant_not_found` → 404

### Phase 5 — Frontend GamePage

**File**: `frontend/src/pages/GamePage.tsx`

**Polling**: Replace one-time `fetchRoom()` with `setInterval` at 2000 ms. Fetch immediately on mount, then every 2 s. `clearInterval` on unmount.

**Canvas rendering** (both roles):
- `useRef<HTMLCanvasElement>` for the canvas element
- `useEffect` triggered by `[room.strokes, currentStroke, canvasRef]` to redraw all committed strokes plus any in-progress stroke
- Render each stroke as a polyline: `moveTo` first point, `lineTo` subsequent points, `stroke()`
- Denormalize coordinates: `x * canvas.width`, `y * canvas.height`

**Drawer-only pointer events**:
- `onPointerDown`: capture pointer, begin `currentStroke` array with normalized first point
- `onPointerMove`: while `isPointerDown`, append normalized point to `currentStroke`
- `onPointerUp`: if `currentStroke.length > 0`, call `api.addStroke()` (fire-and-forget; polling will confirm sync), clear `currentStroke`
- `canvas.style.cursor = "crosshair"` for drawer; `"default"` for guesser

**Guesser guess input** (shown only when `!isDrawer`):
- State: `guessText: string`, `hasGuessedCorrectly: boolean`
- Initialize `hasGuessedCorrectly` from `room.guesses.some(g => g.participantId === participantId && g.isCorrect)` — restores state after page refresh
- On submit: POST via `api.submitGuess()`, if `isCorrect` → set `hasGuessedCorrectly = true` immediately
- Input and button disabled when `hasGuessedCorrectly`
- Show "Correct!" label when `hasGuessedCorrectly`

**Guess history** (all players, in right sidebar or below canvas):
- Render `room.guesses` as an ordered list
- Each entry: `{name}: "{text}"` with a CSS class distinguishing correct vs. incorrect
