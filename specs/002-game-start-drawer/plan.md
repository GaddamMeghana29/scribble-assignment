# Implementation Plan: Game Start & Drawer Flow

**Branch**: `scribble-app` | **Date**: 2026-06-04 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/002-game-start-drawer/spec.md`

## Summary

Extend the existing Scribble Assignment to support starting a game: the host clicks Start Game, the room transitions to `"game"` status, the host navigates immediately to the Game screen, and guests auto-redirect within ~2 s via lobby polling. The drawer (always the host) is identified on the Game screen. The secret word is shown to the drawer only; guessers see underscores matching the word length. All state lives in the existing in-memory room store.

**Constraints**: No new top-level dependencies. No WebSockets. No persistent storage. All changes must extend existing patterns.

**Scale/Scope**: 2–6 players per room, single room per session, assignment duration only

## Implementation Approach

### Phase 1 — Backend Model Changes (blocking)

Extend `backend/src/models/game.ts`:
- `RoomStatus`: `"lobby"` → `"lobby" | "game"`
- `Room`: add `drawerId: string | null` and `currentWord: string | null`
- `RoomSnapshot`: add `drawerId: string | null`, `currentWord: string | null`, `wordLength: number | null`, and update `status` type

### Phase 2 — Backend Service Changes

In `backend/src/services/roomStore.ts`:
- `createRoom()`: initialise `drawerId: null`, `currentWord: null` in the Room object literal
- `startRoom()`: after existing host/player-count validation, set `room.status = "game"`, `room.drawerId = caller.id`, `room.currentWord = STARTER_WORDS[room.participants.length % STARTER_WORDS.length]`, `room.updatedAt = now()`, save back, return `{ room: cloneRoom(room) }`
- `toRoomSnapshot()`: remove `void viewerParticipantId` no-op; compute `isDrawer = viewerParticipantId != null && viewerParticipantId === room.drawerId`; return `drawerId: room.drawerId`, `wordLength: room.currentWord?.length ?? null`, `currentWord: isDrawer ? room.currentWord : null`

### Phase 3 — Frontend Type + State Changes

In `frontend/src/services/api.ts`:
- Update `RoomSnapshot` interface: `status: "lobby" | "game"`, add `drawerId: string | null`, `currentWord: string | null`, `wordLength: number | null`

In `frontend/src/state/roomStore.ts`:
- Initialise `participantId` from `sessionStorage.getItem("scribble_participantId")` in the class state
- In `setRoomSession()`: call `sessionStorage.setItem("scribble_participantId", response.participantId)`

### Phase 4 — Frontend Page Changes

In `frontend/src/pages/LobbyPage.tsx`:
- Add `useEffect` that navigates to `/game` (replace) when `room?.status === "game"` — this is the guest auto-redirect

In `frontend/src/pages/GamePage.tsx`:
- Add one-time `useEffect` that calls `roomStore.fetchRoom()` on mount (re-fetches room with `participantId` from sessionStorage)
- Derive `drawer = room.participants.find(p => p.id === room.drawerId) ?? null`
- Derive `isDrawer = participantId != null && participantId === room.drawerId`
- Derive `wordDisplay`: if `isDrawer && room.currentWord` → show word; else if `room.wordLength != null` → show `Array.from({ length: room.wordLength }, () => "_").join(" ")`; else → null
- Render drawer name visible to all; render "You are the Drawer" label only when `isDrawer`; render `wordDisplay` in Secret Word card

### Phase 5 — Tests

In `backend/src/services/roomStore.test.ts`, add:
- `startRoom()` sets `status: "game"`
- `startRoom()` sets `drawerId` to host's participant ID
- `startRoom()` selects a word from `STARTER_WORDS`
- `startRoom()` with 2 players selects index 2 (`"castle"`)
- `toRoomSnapshot()` always includes `drawerId`
- `toRoomSnapshot()` returns `currentWord` for the drawer
- `toRoomSnapshot()` returns `currentWord: null` for a guesser
- `toRoomSnapshot()` returns correct `wordLength` for both viewer types
