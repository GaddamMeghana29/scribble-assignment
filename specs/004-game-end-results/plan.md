# Implementation Plan: Game End & Results

**Branch**: `scribble-app` | **Date**: 2026-06-04 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/004-game-end-results/spec.md`

## Summary

Extend the existing Scribble Assignment to support game completion: when a guesser submits the correct word, `submitGuess()` atomically transitions the room to `"ended"` state. All players (drawer and guessers) are auto-redirected to a new Results screen via the existing ~2-second polling mechanism. The Results screen reveals the secret word, names the winner, and shows the complete guess history. The host can reset the room back to `"lobby"` with a "Play Again" action, auto-redirecting all players to the Lobby screen. All state lives in the existing in-memory room store; no new dependencies are introduced.

## Technical Context

**Language/Version**: TypeScript 5.x (Node.js 20+ backend, React 18 frontend)

**Primary Dependencies**: Express 5 (backend), React Router v6 (frontend), Vitest (backend tests), Zod (schema validation) — all already present; no new packages

**Storage**: In-memory `Map<string, Room>` — no database

**Testing**: Vitest (`backend/src/services/roomStore.test.ts`)

**Target Platform**: Local development web app (Node.js server + Vite dev server)

**Performance Goals**: All players navigate to Results within ~2 s of correct guess; all players navigate to Lobby within ~2 s of Play Again

**Constraints**: No new top-level dependencies. No WebSockets. No persistent storage. All changes must extend existing patterns (constitution Principles I–V).

**Scale/Scope**: 2–6 players per room, single active game per room

### Phase 2 — Backend Service Changes

**File**: `backend/src/services/roomStore.ts`

**2a. Modify `submitGuess()`** — atomically end the game on correct guess:

After the existing `room.guesses.push(guess)` line, add:
```typescript
if (isCorrect) {
  room.status = "ended";
}
```
(The existing `if (room.status !== "game")` guard at the top already satisfies FR-013 — when the room is `"ended"`, the guard rejects the submission with `not_in_game`.)

**2b. Modify `toRoomSnapshot()`** — reveal word when ended:

Replace the `currentWord` line:
```typescript
// Before:
currentWord: isDrawer ? room.currentWord : null,

// After:
currentWord: (isDrawer || room.status === "ended") ? room.currentWord : null,
```

**2c. Add `resetRoom(code, participantId)`** — host-only reset to lobby:

```typescript
export function resetRoom(code: string, participantId: string) {
  const room = rooms.get(code);
  if (!room) return { error: "room_not_found" as const };
  const caller = room.participants.find((p) => p.id === participantId);
  if (!caller?.isHost) return { error: "not_host" as const };
  if (room.status !== "ended") return { error: "not_ended" as const };
  room.status = "lobby";
  room.drawerId = null;
  room.currentWord = null;
  room.strokes = [];
  room.guesses = [];
  room.updatedAt = now();
  rooms.set(room.code, room);
  return { room: cloneRoom(room) };
}
```

**File**: `backend/src/api/rooms.ts` — add:

2. Add route handler after `/:code/guesses`:

```typescript
router.post("/:code/reset", (request, response, next) => {
  try {
    const { code } = roomCodeParamsSchema.parse(request.params);
    const { participantId } = resetRoomSchema.parse(request.body);
    const result = resetRoom(code.toUpperCase(), participantId);

    if ("error" in result) {
      if (result.error === "room_not_found") throw new HttpError(404, "Room not found");
      if (result.error === "not_host") throw new HttpError(403, "Only the host can reset the room");
      if (result.error === "not_ended") throw new HttpError(400, "Room is not ended");
    }

    const { room } = result as { room: Parameters<typeof toRoomSnapshot>[0] };
    response.json({ room: toRoomSnapshot(room, participantId) });
  } catch (error) {
    next(error);
  }
});
```

### Phase 6 — New ResultsPage

**File**: `frontend/src/pages/ResultsPage.tsx` (new file)

Component responsibilities:
1. Guard: if no room, navigate to `/` (same pattern as LobbyPage/GamePage)
2. Guard: if `room.status !== "ended"`, navigate to appropriate screen based on status (`"lobby"` → `/lobby`, `"game"` → `/game`)
3. Polling: `setInterval` at 2000 ms (same pattern as GamePage)
4. On each poll: if `room.status === "lobby"`, `navigate("/lobby", { replace: true })`
5. Derive winner: `const winner = room.guesses.find(g => g.isCorrect) ?? null`
6. Render:
   - Revealed secret word (`room.currentWord`)
   - Winner name (`winner?.name` or "No winner recorded")
   - Guess history (same `<ol>` pattern as GamePage, with correct/incorrect distinction)
   - Host: "Play Again" button that calls `api.resetRoom(room.code, participantId)` on click
   - Non-host: message "Waiting for the host to start a new game"

```typescript
import { useCallback, useEffect } from "react";
import { useNavigate } from "react-router-dom";
import { api } from "../services/api";
import { Card } from "../components/Card";
import { RoomCodeBadge } from "../components/RoomCodeBadge";
import { useRoomState, useRoomStore } from "../state/roomStore";

export function ResultsPage() {
  const navigate = useNavigate();
  const roomStore = useRoomStore();
  const { room, participantId } = useRoomState();

  useEffect(() => {
    if (!room) {
      navigate("/", { replace: true });
      return;
    }
    if (room.status === "lobby") {
      navigate("/lobby", { replace: true });
      return;
    }
    if (room.status === "game") {
      navigate("/game", { replace: true });
      return;
    }
  }, [navigate, room]);

  useEffect(() => {
    roomStore.fetchRoom().catch(() => {});
    const id = setInterval(() => {
      roomStore.fetchRoom().catch(() => {});
    }, 2000);
    return () => clearInterval(id);
  }, [roomStore]);

  const handlePlayAgain = useCallback(async () => {
    if (!participantId || !room?.code) return;
    try {
      await api.resetRoom(room.code, participantId);
    } catch {
      // polling will detect lobby state anyway
    }
  }, [participantId, room?.code]);

  if (!room || room.status !== "ended") return null;

  const isHost =
    participantId != null &&
    room.participants.find((p) => p.id === participantId)?.isHost === true;

  const winner = room.guesses.find((g) => g.isCorrect) ?? null;

  return (
    <section className="panel results-page">
      <div className="results-page__header">
        <div>
          <span className="section-kicker">Game Over</span>
          <h1>Results</h1>
        </div>
        <RoomCodeBadge code={room.code} />
      </div>

      <div className="results-page__layout">
        <Card title="Secret Word">
          <p className="word-display" style={{ fontSize: "1.5rem", fontWeight: 700 }}>
            {room.currentWord ?? "—"}
          </p>
        </Card>

        <Card title="Winner">
          {winner ? (
            <p style={{ fontSize: "1.25rem", fontWeight: 600 }}>{winner.name}</p>
          ) : (
            <p>No winner recorded</p>
          )}
        </Card>

        <Card title="Guess History">
          {room.guesses.length === 0 ? (
            <p>No guesses were submitted.</p>
          ) : (
            <ol className="player-list">
              {room.guesses.map((g, i) => (
                <li
                  key={i}
                  style={{
                    color: g.isCorrect ? "#16a34a" : undefined,
                    fontWeight: g.isCorrect ? 600 : undefined
                  }}
                >
                  <span>
                    <strong>{g.name}</strong>: {g.text}
                  </span>
                  {g.isCorrect && <span className="player-list__meta">✓ correct</span>}
                </li>
              ))}
            </ol>
          )}
        </Card>

        <Card title="Next Game">
          {isHost ? (
            <button className="button button--primary" onClick={handlePlayAgain}>
              Play Again
            </button>
          ) : (
            <p>Waiting for the host to start a new game…</p>
          )}
        </Card>
      </div>
    </section>
  );
}
```

### Phase 8 — Tests

**For modified `submitGuess()`** (game-end behavior):
- `submitGuess` transitions room to `"ended"` when guess is correct

- `resetRoom` preserves existing participants

- `toRoomSnapshot` reveals `currentWord` to non-drawer when status is `"ended"`
- `toRoomSnapshot` still hides `currentWord` from non-drawer when status is `"game"`
